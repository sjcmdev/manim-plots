### B.1 Type boundary and Ruff experiment

The brief's premise “Manim ships no types” is false for these installations: both contain `manim/py.typed`; `Axes.__init__` and `VMobject.points` have inline annotations. An external mypy probe resolves `Axes` to its real constructor, `VMobject.points` to `NDArray[np.float64]`, and `Axes().c2p` to a callable returning `ndarray[..., dtype[Any]]`. Constructor `axis_config` is `dict[Any, Any]`, geometric `**kwargs` are `Any`, and `set_stroke.background` is `Any`. Thus `ignore_missing_imports` does **not** erase all of Manim to `Any`; it suppresses genuinely missing/untyped imports. It does not validate numeric array rank, finite values or protocol invariants. Strict annotations plus explicit adapters/validation are necessary; a cast alone does not close F-1002. Evidence: `number_line.py::NumberLine.__init__`, `:141` (0.21.0); `coordinate_systems.py::Axes.__init__`, `:1931` (0.21.0); mypy probe in the command ledger.

Installed Ruff's own documentation (`ruff rule TID251`, `ruff config lint.flake8-tidy-imports.banned-api`) says bans apply to imports **and accesses**, and can be bypassed by dynamic import. An external src-layout experiment found **six TID251 errors**: aliased Manim import, `from manim import`, both forms of relative mobjects import, `sys._getframe()` and `inspect.currentframe()`. It did **not** flag `frame.f_code` or `frame.f_locals` on a supplied frame. Directory-specific configurations can enforce the import rule; one per-file ignore for TID251 cannot distinguish the import bans from the stack bans. Keep the small planned AST check for unrestricted frame-attribute access and the core's allowed imports; using Ruff for the import subset is optional, not grounds to add multiple configuration files now. Evidence: `docs/adr/0001-architecture.md:49` through `:58` and the external probe.

**D1 — major — “Signatures are the contract” stops before several core contracts.** ADR 0001 supplies typed Scale, Locator, Formatter, CompiledMap, Bounds and Source, but Node is only the untyped D6 sketch and there is no typed Map/Payload constructor, Shape callable or parameter/tracker interface (`docs/adr/0001-architecture.md:94`–`:97`, `:129`–`:133`, `:232`). **D2 — major — Filtering/smoothing/clipping lack a consistent geometry rule.** `docs/scope.md:44` says an array source filters by range; `:179` requires clipping curves. ### Contract and lifecycle findings

**E1 — blocker — `contains` is missing generation context.** For a legal density-aware locator, `values(0,1,linear,max_ticks=1)` may return [0] and the same call with max_ticks=3 may return [0,.5,1]. `contains(.5,0,1,linear)` receives identical arguments in both cases. Caching the last `values` call makes it order-dependent; the tick pool calls it on multiple ranges/copies. Evidence: `docs/adr/0001-architecture.md:139`–`:162`; F-408 at `docs/scope.md:129`. **Fix:** new ADR passing the same density context or explicit tick set. Define one key namespace/merge rule for generated and Fixed entries and for major/minor roles. Cost: small.

**E2 — blocker — Finish conditions overlap and deferred actions lack priority.** The target row (`docs/adr/0001-architecture.md:297`) can coincide with the start row (`:299`) when two artist targets currently have identical geometry but different sources/bindings. A remover is also allowed to have a target, and its resume precedes cleanup in Manim (`animation.py::Animation.finish`, `:225`–`:227`, 0.21.0/0.22.0). A refresh deferred by `:302` can coincide with a plain-target S transition; `become` cancels targets at `:303`, but the generic owner-finish rows do not mention cancellation. Different row order selects a different source or attached state. **Fix:** new ADR with disjoint event predicates and a state record containing origin, owners, pending/cancelled targets and refresh; specify cleanup as a separate event and give its priority. Test every combination above, not only every isolated table cell. Cost: medium.

**E3 — major — Protocol fields described as read-only are writable in the type contract.** `CompiledMap.is_affine` and Bounds.lower/upper are plain writable protocol attributes (`docs/adr/0001-architecture.md:197`–`:210`), although the Source receives a read-only view (`:218`). A third-party Source can assign `map.is_affine=False` without a type error; arrays can also be mutated. **Fix:** new ADR expressing the intended read-only public properties, and document/enforce snapshot or read-only-array ownership for Bounds/Payload. Do not claim that `@dataclass(frozen=True)` alone makes NumPy buffers immutable. Cost: small.

**E4 — major — Own geometry/adoption has no singular-frame rule.** The artist's own transform runs **before** its frame (`docs/scope.md:45`, `:207`), while collapsed frames are an accepted limit (`docs/grill-log.md:526`–`:529`). After `ax.scale(0)`, an affine frame maps every local point to the same scene point. No finite local transform can make `curve.shift(RIGHT)` produce a translated scene point through that frame. Likewise adopting a plain Circle into S requires a local preimage that does not exist. The p2c refusal rule does not specify what these mutating operations do. **Fix:** new ADR defining an atomic refusal or explicit detachment policy for an operation needing a nonexistent inverse; list it as a migration limitation, and test singular/near-singular frames and transient animation buffers separately. This does not require dropping non-affine support. Cost: small/medium.

Scale/Locator/Formatter are structurally implementable subject to E1/D3/D4; Source/CompiledMap/Bounds and Payload need C1/D1/E3 resolved. Date adapters fit the float engine; polar can add an internal coupled Node and nonrectangular Bounds; a second scale can use a second Map sharing the frame; future 3D needs a new frame implementation, not necessarily a new public array type. These are extension arguments, not proof that the absent signatures are complete. F-201 already limits inversion to invertible maps, so polar's branch restriction is not by itself a contradiction.
