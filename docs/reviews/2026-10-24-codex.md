# Independent MVP1 freeze review — Codex — 2026-10-24

## 1. Verdict

**Freeze after the listed blockers.** The public payload and identity contracts contain contradictions, and lifecycle, scheduling and compatibility decisions still require implementation to invent observable behaviour.

This reviews the design, not a production engine: `src/manim_plots/__init__.py:3-5` exposes only a version. The requested documents and both PoC 4 implementation files were read; the other reviewer's report was not read. No network, installation, commit or PoC rerun was used. The only repository file written is this report.

Evidence notation: repository references are `path:line` (occasionally a short range). `CS`, `FN`, `NL`, `UU`, `VT`, `TR` below mean, respectively, `mobject/graphing/coordinate_systems.py`, `mobject/graphing/functions.py`, `mobject/graphing/number_line.py`, `animation/updaters/mobject_update_utils.py`, `mobject/value_tracker.py`, and `animation/transform.py` under the installed **Manim 0.21.0** root `.venv/Lib/site-packages/manim/`. Version 0.22.0 was read at the exact uv-cache path in the prompt. Manim references give the symbol before the line; numbers are 0.21.0 unless explicitly labelled otherwise. A design gap below is not a claim that an unimplemented feature already fails a runtime test.

Costs below are relative implementation/review costs: **small** means a local contract decision and focused check, **medium** crosses pipeline or lifecycle boundaries, **large** adds or changes a representation. They are not time estimates.

## 2. Freeze blockers

1. **A map can produce a payload that its own frozen validator forbids.** `docs/scope.md:58-74` makes `valid` the sole invalidity channel and orders Map to carry it and segments untouched. `docs/adr/0001-architecture.md:100-102` requires an out-of-domain scale input to become NaN; `docs/scope.md:253-255` rejects a non-finite coordinate marked valid or covered by a valid path segment. A legal finite path Payload containing a negative x becomes invalid under log if Map retains `valid=None` and its full segment. Making Source anticipate every downstream domain/finite-output failure could avoid this, but that obligation is not specified either. **Fix:** specify who combines incoming validity with each node's domain/finite-output mask and rebuilds path coverage, before the next stage validates/consumes a Payload. Define whether intermediate results are validated Payloads or a different internal type. **Cost: medium**, but no new architectural layer is needed.

2. **The field paper check does not carry the values a field artist needs.** The frozen five fields contain positions, connectivity and validity, but no scalar/vector samples (`docs/scope.md:56-79`); Source exposes only coordinate output (`docs/adr/0001-architecture.md:179-186`). Nevertheless the check claims one source can supply contours, arrows and streamlines (`docs/scope.md:331-355`). Two vector fields on the same sampling grid have identical declared positional payloads and different arrows; a `Payload -> Payload` Shape cannot distinguish them. Encoding attributes as extra coordinates also makes Map transform them, contrary to the distinction at `docs/scope.md:58`. **Fix:** work through one scalar contour and one vector-field payload, including component shape and validity, or keep this unimplemented branch internal and explicitly extensible instead of freezing a supposedly complete public return type. Also specify `Source.at` argument/output shapes for curve, point-set and region sources. **Cost: medium to large** if the five-field return type stays public; small scope reduction if it does not.

3. **Locator identity is not defined across the operations which must preserve it.** D10 keys identity by data value (`docs/grill-log.md:279-284`); ADR allows a MaxN key relative to its latest range (`docs/adr/0001-architecture.md:269-274`). Pool construction asks one locator about many future ranges (`poc4/model.py:379-384`). No contract says that the same value keeps its key, or that one key cannot denote different values, across those calls, locator replacement, scale changes or major/minor roles. Per-call uniqueness in F-413 does not supply that invariant. **Fix:** define persistent identity separately from current membership, or require stable value keys with explicit namespaces and invalidation rules. Specify the identity of explicit off-grid entries for which generated `key` returns None. **Cost: medium**; the public Locator contract is affected.

4. **The tick pool has neither a correct schedule contract nor a late-key policy.** The omission is explicit in `PLAN.md:307-309,488-490` and ADR `:254-256`. PoC uses `linspace(0,1,ceil(run_time*fps)+1)` (`poc4/model.py:376-384`), while Manim renders `arange(0,run_time,1/fps)` (`scene.py::Scene.get_time_progression`, `:1097-1101`) and computes alpha from actual time (`scene.py::Scene.update_to_time`, `:1704-1707`). These differ even without nesting; see the arithmetic check in section 6. Composition adds child time remapping and lag. **Fix:** define coverage of actual child interpolation calls, including endpoint, skipped playback, rate-function reversal/overshoot, changing label-space estimates and keys first discovered at runtime. Define pool ownership/pruning under nested animations. A documented late insertion/error policy is required; a sampled union is not coverage of every real alpha. **Cost: medium**; a paragraph and one happy-path test, as the earlier review proposes, underestimate it.

5. **The lifecycle contract does not determine ownership under overlap, copy, cross-system adoption or early introducer capture.** See the marked cells in section 5. PoC's leaf uses a single `_transient` flag and candidate (`poc4/model.py:650-675,686-696`), although its frame keeps animation-specific suspension entries (`:145,165-176`). `refresh()` unconditionally exits transient mode (`:741-746`); `become()` unconditionally adopts/rebuilds (`:719-723`). Constructor-time points predate the available begin hook (`growing.py::GrowFromCenter.__init__`, `:132-133`; `GrowFromEdge.__init__`, `:172-173`). The promised replacement transfer in F-708 is explicitly absent in PoC (`docs/poc4-keyed-alignment.md:159-178`). **Fix:** adopt a transition table with transaction ownership and precedence; explicitly reject combinations that 0.1 will not support; define clone binding and adoption across systems; decide an implementable introducer policy and replacement handoff/collision rules. **Cost: medium to large**, not just an Enum rename.

6. **The inverse guarantee contradicts accepted frame limits.** F-201 promises inversion over the whole range (`docs/scope.md:90`), while D18 accepts another inverse branch and collapsed frames (`docs/grill-log.md:525-528`). Squaring a complex coordinate maps both (-1,0) and (1,0) to (1,0): no unique inverse exists over that range. F-207 also leaves projection versus refusal undecided (`docs/scope.md:96`). **Fix:** restrict the round-trip guarantee to valid points on injective, nonsingular portions of the supported mapping; state off-plane tolerance/policy, extrapolation, non-convergence and branch selection. Distinguish exact inversion of a sampled interpolant from inversion of the original nonlinear function. **Cost: small contract change; medium numeric/error tests.**

7. **“Same signature and defaults” has unresolved exceptions at a common migration entry point.** F-1009 (`docs/scope.md:231`) accepts NumberLine configuration, but native `scaling=LogBase()` interprets range endpoints as exponents (`number_line.py::NumberLine.__init__`, `:193-198`; `scale.py::LogBase.function`, `:149-152`). The new engine's log range consists of data values and normalises nonpositive endpoints (F-311, `docs/scope.md:111`). In `CS::LogScalingExample`, `:1907-1916`, y=(-2,6) means [0.01,1e6] in Manim, not [eps,6]. F-803's default colour cycle also conflicts with the unqualified same-defaults promise. **Fix:** choose an explicit Manim-scaling adapter versus an intentional migration difference, and state its range/readback semantics; enumerate the default exceptions. Decide the constructor/facade coverage identified in section 4 rather than treating a method-name inventory as complete parity. **Cost: small documentation decision; medium adapter work if exact migration is promised.**

8. **The performance gate does not define the work being frozen.** F-1001 names four artists and 8,000 samples but not the parameter, labels/locator, warm state, frame motion, path or timer boundary (`docs/scope.md:223`). PoC excludes adaptive sampling, clipping and real labels and excludes alignment/simulation from rebuild timing (`docs/poc3-stack-context.md:339-350`; `docs/poc4-keyed-alignment.md:348-372`). A Succession classifier can run during playback (`docs/poc3-stack-context.md:217-221`), outside that timer. **Fix:** define the production fixture and sum of exclusive engine work per frame, including updater/stack/frame checks, ticks/layout/label assembly and work at during-play child starts. Record setup costs separately, both affine and nonlinear workloads, sample-count meaning and warm-cache preconditions. Keep Cairo rasterisation/encoding outside a pipeline gate. **Cost: small specification, medium benchmark integration.**

## 3. Findings

### A. Architecture

**A1 — major: retain the two layers, but move decisions as well as numerical formulas out of the adapter.** ADR `:32-37,213-216` already places frame maths and placement Nodes in core. Pure frame fitting, bilinear evaluation/inversion and cached weight generation need a named home (existing `core/nodes.py` is sufficient). Role/key union, active-set merge and a transition reducer can likewise operate on plain values; only reading frames/locals, obtaining grid arrays, suspending mobjects, preserving live identities, and scene replacement need Manim objects. PoC currently mixes these at `poc4/model.py:133-201,225-302,371-418,626-746`. **Fix:** document these boundaries without introducing State subclasses, an event bus, ports for every class, or more packages. This makes B1/B3/B4/B5 testable without a render. “Only numbers” need not exclude a pure state transition over enums/tokens.

**A2 — major: assess all four arch-crew findings with narrower prescriptions.**

| Earlier finding | Assessment and required disposition before freeze |
|---|---|
| 1, isolate the volatile seam (`docs/architecture-review-2026-10-24.md:42-53`) | Valid for frame/code/local reads; put the rule in ADR now. The proposed blanket ban on underscore attributes outside context is broader than the demonstrated seam. Animation copies, target buffers, outline repair and native alignment also rely on internals (`poc4/model.py:628-635,678-696`; Manim `TR::Transform.begin`, `:204-211`). Enumerate those dependencies or move their access behind small adapter operations too. One AST assertion cannot establish semantic isolation or identify which underscore attribute belongs to Manim rather than us. |
| 2, explicit state machine (`:54-68`) | Required now, but attached/transient/detached alone is insufficient. Frozen-frame selection, active animation owners, target candidates and cleanup are partly orthogonal. A flat Enum replacing five booleans would conceal valid combinations. Use section 5 to define decisions; then choose the smallest representation. |
| 3, name frame maths' core home (`:69-80`) | Valid, editorial and small. No extra `frame` subsystem is required. ADR already mandates pure numerical functions at `:213-216`; naming `nodes.py` closes the ambiguity. |
| 4, pool schedule (`:81-92`) | Valid freeze blocker, with the larger coverage/cost described in B4. Root run_time × fps does not specify a nested child's actual alpha schedule. Decide label-space/locator state, role ownership, opacity and late keys as well. |

The assertion that everything outside context uses only public Mobject methods (`docs/architecture-review-2026-10-24.md:23`) is too strong for the named PoC and repair design. **Fix:** describe one reviewed dependency inventory, not a claim that the seam is already fully isolated.

**A3 — major: lifecycle gaps U1–U10 are contract decisions, not requests for another broad PoC.** Evidence and affected cells are in section 5. Each identifier is a finding:

- **U1, pending data:** define whether data changes during transient geometry apply on resume, lose to an adopted target, or queue until after cleanup. F-903/F-905 (`docs/scope.md:202-204`) do not set precedence; PoC adoption can replace binding/source (`poc4/model.py:699-717`). **Fix:** one rule for parameters, callable sampling and candidate adoption, including detached origins.
- **U2, multiple owners:** define nesting, independent overlap and outer/inner finish order, including an artist and its system. F-906 names composition but no transaction ownership (`docs/scope.md:205`); PoC clears the leaf Boolean on every resume (`poc4/model.py:673`) although the frame removes a matching animation entry (`:165-167`). **Fix:** owner-aware transitions or explicit unsupported-overlap errors. Do not require one test for every arbitrary Cartesian product; cover each distinct ownership rule.
- **U3, removal/cleanup overlap:** define which animation owns the retained buffer if a remover finishes while another animation still writes, or if its cleanup follows another animation's finish. Manim cleans each root immediately after finishing it (`scene.py::Scene.play_internal`, `:1389-1393`), and shifted FadeOut writes again in cleanup (`fading.py::FadeOut.clean_up_from_scene`, `:190-192`). **Fix:** specify cleanup transaction and deterministic conflict handling.
- **U4, target provenance:** define source, system, local placement, parameters and scene identity for `Transform`/`become` across systems, and for a detached starting subject. PoC adopts a Derived source/placement without adopting or converting its system (`poc4/model.py:699-706`). Thus a target made on displaced/differently scaled axes is not covered by a same-system proof. **Fix:** choose retained binding with coordinate conversion versus binding transfer, and specify plain-target detached geometry and reattachment.
- **U5, `become` during animation:** F-905 gives no precedence relative to the prepared target or suspension. PoC immediately rebuilds (`poc4/model.py:719-723`) even when transient. **Fix:** explicitly forbid it, defer it, or define cancellation/replacement of the active candidate. Also cover native `become` keyword arguments (`mobject.py::Mobject.become`, `:3182-3190`), rejected by the PoC at `:720-721`.
- **U6, introducers before begin:** the state seen by constructor queries cannot be repaired generically merely by refreshing at suspension. Evidence: B5 and `poc4/model.py:628-635`. Reattaching on every getter would instead violate detached re-add semantics and make an innocent `get_center()` attach. **Fix:** choose an explicit early operation, a bounded set of supported constructor dependencies, or a documented limitation; reconcile it with PLAN's no-list rule (`PLAN.md:176-182,484-487`).
- **U7, `refresh()` during animation:** it currently clears `_transient` (`poc4/model.py:741-746`), exposing following temporary writes to permanent attribution. F-111/F-905 never specify whether refresh is legal then. **Fix:** error or defer while any transaction owns the buffer; specify behaviour during cleanup.
- **U8, detached flavours:** removed-buffer retention, plain-target adoption, artist-owned operations, frame movement and refresh do not have a single defined relationship. PLAN says a plain target is kept in system-local coordinates (`PLAN.md:152-157`); PoC freezes detached getters completely (`poc4/model.py:586-590`) and explicitly tests no motion after removal (`docs/poc4-keyed-alignment.md:182-187`). **Fix:** say whether retained geometry is an absolute scene snapshot or a local shape; separate states if their later motion differs. Clarify that lifecycle detachment need not erase registration/original source.
- **U9, manual/unsuspended operation:** F-903 concerns suspension “of an animation”; bare `suspend_updating()` and default-false animations are different. The latter exist (`movement.py::MoveAlongPath.__init__`, `:192`; `PhaseFlow.__init__`, `:151`). F-1008 records PhaseFlow growth but not a general manual suspend/resume rule. **Fix:** keep manual updater suspension distinct from animation buffer ownership, and state how custom animations without suspension are treated.
- **U10, copying:** freeze ownership for `artist.copy()`, `ax.copy()`, either VGroup child order, and copies made while transient/frozen/detached. PoC shares source/tracker/binding, preserves flags/frozen-frame state, resets candidates and re-registers copies (`poc4/model.py:434-447,725-739`). Historical measurements do not make that a public contract. **Fix:** state which mutable objects are shared, how normal copies become usable independently of a live transaction, and how internal animation copies differ. In particular, copied descriptors/bindings must not mutate live trackers while `.animate` prepares a target (`mobject.py::_AnimationBuilder.__init__`, `:3416-3418`).

**A4 — major: replacement transfer needs more than changing a reference.** F-708 promises transfer (`docs/scope.md:177`); L3 explicitly leaves ownership at the removed axes (`docs/poc4-keyed-alignment.md:162-178`). The PoC is honest evidence of a missing mechanism, not contrary normative documentation. A target may already have registered artists; locators/scales/ranges and per-artist local transforms may differ. **Fix:** specify an atomic handoff at native scene replacement, including collisions, pre-existing target artists, source axes re-add, registry/legend membership and subsequent motion. Do not call the feature proved by L3.

**A5 — major: simulation is more than an accepted extra callback cost.** `poc4/model.py:179-199` runs setup/begin/finish/cleanup on a `SimulationScene` exposing only add/remove/replace/family (`:450-465`). A valid custom animation may use other Scene state, fail on this double, or depend on intermediate interpolation/history. D20 authorises external callback effects, but supplies no exception policy, deterministic endpoint assumption or nesting rule (`docs/grill-log.md:559-564`). **Fix:** define simulation failure and unsupported Scene access; classify at the actual child begin; cache by transaction owner; state that endpoint simulation is a policy approximation for stateful/custom animations. Do not promise arbitrary callbacks are isolated. Counts depend on nested classifications and begin/finish/cleanup, rather than exactly one extra callback invocation (`docs/poc4-keyed-alignment.md:318-324`).

**A6 — major: Source, Shape and frame feedback do not agree about screen-space sampling.** Source receives only `CompiledMap` and bounds (ADR `:179-186`), but Map ends before artist placement and frame (F-105, `docs/scope.md:42`; `PLAN.md:195-201`). Adaptive error measured there cannot see an artist's nonlinear placement or a nonlinear/strongly enlarged frame. Curvature in local Map coordinates is not screen curvature; both D6 (`docs/grill-log.md:128-131`) and ADR `:184-185` claim the latter. **Fix:** define the read-only sampling metric/evaluator as the complete current forward map, or explicitly constrain the error guarantee and refresh density after placement changes. Supply clipping bounds to Shape explicitly or through its owning closure; `Payload -> Payload` alone does not identify a viewport. This can remain a plain function, without a dependency graph.

**A7 — major: the future-system paper checks must be repeated against the current representation.**

| Case | Result against the proposed freeze |
|---|---|
| Date/time | **Fits** an adapter above float coordinates, conditional on B3's stable keys and a declared epoch shared by all entry points. Full-list formatting already supports contextual calendar labels (`docs/scope.md:288-308`). A DateLocator may enumerate irregular month boundaries; no constant-step assumption is necessary. |
| Calculus / area / Riemann sums | **Fits** source point evaluation plus path/region output; a wrapper Source can differentiate analytically/numerically. But specify array/scatter point-query policy: `Source.at(t)` has no parameter-shape or interpolation/domain semantics (ADR `:179-182`), and non-monotone/repeated-x array input is allowed by F-703 without a functional y(x) guarantee (`docs/scope.md:172`). Missing samples cannot be called “exact” interpolation. |
| Polar / non-separable Map | **Fits conditionally** if public Scale remains explicitly one-dimensional and the internal coupled Node can have a multivariate domain and partial/nonunique inverse. Polar coordinates map to a local Cartesian plane before the planar frame. Do not apply F-109's monotonic-direction requirement to every coupled node (`docs/scope.md:46`; ADR `:85,113-116,251-265`). Node is not exported in 0.1, so its future implementation can change without breaking third parties. |
| Scalar/vector fields | **Does not yet fit the declared payload**, for B2. A contour's scalar level and an arrow's vector are not merely cell connectivity. Scope's conclusion at `:327-355` is stronger than its contract. |
| 3D | **No public break is forced if frame internals stay private and Source shapes are generic**, but implementation does require a new volumetric/3D placement representation or a narrower geometric surface. Single ownership of an artist need not mean one Map per system forever. Freeze the ownership distinction, not an internal hard-coded one-map storage layout (`docs/scope.md:49,162`; `docs/grill-log.md:153-155`). |

**A8 — major: freeze the benchmark's accounting, not the PoC's current favourable number.** B8 applies to F-1001/F-915/F-918. Include per-frame callable evaluation, binding comparisons, full-grid checks, stack lookups, role/key updates, label-space decisions and glyph assembly once, with disjoint timers. Use moving affine and genuine nonlinear frames, not only a stationary frame with the bilinear branch forced. Bound measured sample/control counts, frame density and dense decorations. Measure pool preparation/copy/simulation as setup, then also charge them to a per-frame engine measurement when a Succession child starts during playback. Keep a separate setup-latency record; no 4 ms requirement for video encoding is implied. The PoC's 19.0558 ms full frame is **not itself a design failure**, as its review note correctly says (`docs/poc4-keyed-alignment.md:480-482`).

### B. Manim compatibility

**B1 — major: live callable resampling changes ordinary Python closure semantics in a published scene.** `CS::CoordSysExample`, `:101-105`, creates 78 graphs using lambdas closing over `n`, without binding n as a default argument. Manim samples at construction (`FN::ParametricFunction.generate_points`, `:160-174`), while F-918 samples again during later frames (`docs/scope.md:217`). On redraw those functions all read the loop's final n, collapsing the family to two repeated powers. Live callables are an explicit D21 decision; the late-binding migration consequence is not stated in D17-D21/F-1008. **Fix:** document `lambda x, n=n: ...` next to loop migration, make the corpus scene a regression, and distinguish “sample pass per frame” from “one function invocation” for adaptive/scalar sampling. No new snapshot mode is required unless maintainers want native construction-time semantics.

**B2 — major: the parity inventory excludes constructors and return structures.** It inventories methods defined on classes (`tests/test_parity_surface.py:48-59`) and checks only names (`:80-91`). It cannot settle a standalone NumberLine/FunctionGraph/ParametricFunction facade, NumberPlane grid construction, `plot_line_graph`'s VDict keys, or label helper return children. Evidence: `CS::Axes.plot_line_graph`, `:2303-2312,2372-2390`; section 4 shows where these are used. **Fix:** add a small migration-surface contract for constructors, defaults, return types/children and ownership. Methods already promised by F-1009 should retain native spellings; do not redesign `get_graph_label` into a legend or `plot_line_graph` into two separately added objects.

**B3 — minor: path-progress semantics need an explicit sampling qualification.** Adaptive sampling is an intentional F-704 improvement (`docs/scope.md:173`), but native `point_from_proportion`, TangentLine and MoveAlongPath operate on the generated VMobject curve, not the Source parameter. `UU::TangentAnimation`, `:90-103`, depends on those queries. The PoC confirms equal paths built from the same controls (`docs/poc2-frame-lifecycle.md:319-322`), not equal progress after changing sampling/smoothing. **Fix:** preserve native VMobject query semantics, document possible trajectory/timing changes after adaptive regeneration, and distinguish them from source-based `i2gp`. Do not promise an adaptive path has native fixed-sampling control points.

**B4 — major: log configuration is a semantic conversion, not just a spelling adapter.** See blocker 7. Also freeze `plot(..., x_range=(a,b,step))` as a sampling override/hint distinct from an axes range triple's tick step (`CS::CoordinateSystem.plot`, `:727-736`; `PLAN.md:418-420`). The PlotExample deliberately compares three sampling choices (`CS::PlotExample`, `:710-721`). Reinterpreting both triples as a locator silently removes its demonstration. `use_vectorized=False` must continue accepting scalar-only functions; only Scale is required to be vectorized (F-304), and the native scalar path is explicit in `FN::ParametricFunction.generate_points`, `:168-174`.

### E. Test strategy and evidence

**E1 — major: the PoC oracle-independence assessment is overbroad.** `docs/architecture-review-2026-10-24.md:147-151` says expected values are independently computed. In L1, expected values and keys call the very locator under test (`poc4/test_keyed.py:109-110`); expected paths use the PoC's own `path` helper (`:119,129-131`), and reference pixels copy actual styles (`:143-146`). Those comparisons can establish placement for the chosen points, but cannot independently establish tick selection, path construction, or preservation of style. Likewise `poc4/test_animations.py:301` compares with `artist.derived()`; the separately computed data oracle at `:306-316` is the useful independent part. **Fix:** label each oracle's claim precisely. Use explicit integer tick sets/table-driven step transitions, independent geometry evaluations and pre-animation style/identity assertions where those properties are at risk. Retain analytic dense samples and native controls; do not replace them with snapshots of model output.

**E2 — major: plain Manim is an oracle only where behaviour is supposed to match it.** The proposed universal per-frame differential (`docs/architecture-review-2026-10-24.md:141,153-155`) conflicts with deliberate live data, following axes, tick fading/densification and regenerated introducers. Its description also strengthens F-906's endpoint requirement (`docs/scope.md:205`) into every-frame parity. **Fix:** three small oracle classes: native differential for unchanged lifecycle/geometry; independent current-data/reference-frame calculations for intentional live behaviour; explicit policy assertions for accepted divergences. A partial Create frame is not meant to equal a complete source plot. Add corpus/default/config checks using real native Axes, not merely a frame-free copy of our simplified hierarchy (`docs/poc3-stack-context.md:532-536`).

**E3 — major: the actual gate does not run the proposed render/matrix portfolio.** `tools/check.py:45-48` runs default pytest; `pyproject.toml:86-89` selects only `tests/` and excludes render tests. PoC contracts assert version exactly 0.21.0 (`poc4/test_manim_contract.py:13-15`). Presently 51 passing tests cover citations, native defect evidence, name inventory and a version smoke test, not F-903..F-918. **Fix:** document a separate offline render/differential invocation on both supported Manims, plus per-version source pins and benchmark command; make it an explicit pre-release/upgrade obligation. Do not represent `tools/check.py`'s default four checks as already executing this portfolio. Production tests can be added as implementation lands; no new PoC run is required for this review.

**E4 — minor: strengthen cheap mathematical oracles without expanding the suite indiscriminately.** Round trips alone allow matching wrong forward/inverse functions (e.g. scaling by 2 and dividing by 2), so supplement them with fixed anchors, interval membership, reversal, clipping-boundary intersections, payload-mask propagation and known scale examples. Evidence: ADR's obligations `:224-228` and the property-only advice in `CONTRIBUTING.md:50-53`. Use the state table to cover distinct transitions and a few overlapping/nested sequences; do not create one render for every syntactically non-empty cell. Existing negative aliasing/cleanup tests must remain labelled negative evidence (`docs/poc4-keyed-alignment.md:374-388`). Keep the portfolio's omission of broad E2E and mutation testing; it does not need extra process layers.

- **D-live / P:** a callable is a live binding (D21/F-918), not a construction-time snapshot. During an animated update it is sampled once per logical frame pass; scalar/adaptive evaluation can call it many times. Frozen waits do not repeatedly sample. A static example does not itself incur a continuous frame loop.
- **D-colour:** F-803 intentionally introduces a colour cycle; four corpus scenes call `.plot` without a colour. This is a **documented capability**, but its palette/consumption/default exception is unresolved. It must not be described as an unchanged default.

## 5. Lifecycle state × event table

States derived from PLAN rules 1–5, F-903..F-907, D19-D21 and PoC 4:

- **A:** attached, outside an owned transient transaction; getter may rebuild.
- **D:** detached retained geometry. Removed-buffer and plain-target variants still need U8's distinction. Scene membership is independent of attachment.
- **T(A), T(D):** transient geometry entered from A or D, starting at early Transform alignment or animation suspension. The origin state, animation owners and candidate provenance must be retained.
- **C:** remover has resumed/detached its subject, but cleanup may still restore/write its buffer; then it becomes D. This phase follows Manim's real finish/cleanup order rather than adding a new public method.
- **F overlay:** an attached artist outside a temporary system animation reads a frozen placement frame; it is **A[F]**, not detached. Inclusion in that animation exempts it (F-916). Active-owner selection for overlap is U2.

`U#` cells are **unspecified contract findings A3/U#**, not silent implementation choices. `—` means the event has a precondition not satisfied by that column (e.g. a *matching active* finish when no transaction is active). Text with “PoC” is evidence of an implementation choice, not a frozen rule.

## 8. Sound as-is

The core/Manim direction, non-parenting registration, native spelling where semantics match, cache-object identity, version-specific source review, and independent native/analytic controls can stay; the 17 listed stack dependencies show no 0.22-specific algorithm break.

Verification limits: the default 0.21 suite and read-only source/arithmetic checks were run; no PoC, render, TeX, full uv matrix or performance run was repeated. The principal remaining risk is freezing unspecified public behaviour and mistaking same-name/source evidence or passing negative PoC tests for compatibility of a production engine.
